# Shopware Bitbucket Pipelines Deployer

### Info
- This is an edited shopware 6 recipe that used GIT to deploy the correct branch

### Usage
- Check and edit `deploy.php` and `bitbucket-pipelines.yml`
- Add them to the root of your project
- Enable Bitbucket Pipelines and test

- Check https://hub.docker.com/r/sidworks/php-deployer/tags
